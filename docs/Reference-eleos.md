# ELEOS 참고 사이트

사용자 제공 참고: https://www.eleos.la/ — 2026-10-12 확인.
ROLAROLA 시각 디자인의 기준은 기존 Figma이며, ELEOS는 화면 구성과 인터랙션의 참고 자료다.

## 실제 확인

- 사진이 화면 전체를 채우는 히어로와 크게 배치한 워드마크.
- 상단의 작은 메뉴, 히어로 하단의 두 개 소개 문구와 밑줄·화살표 CTA.
- 넓은 여백, 모노스페이스 계열 텍스트, 비대칭 소개 영역과 2열 사진 목록.
- 개발 브라우저 확인에서 nav의 position은 sticky였다.
- 페이지가 GSAP / ScrollTrigger / SplitText / Lenis 스크립트를 로드하는 것을 확인했다. 라이브러리 존재만으로 모든 효과의 트리거나 정확한 duration·easing을 확인한 것은 아니다.

## ROLAROLA와 연결되는 지점

1. 히어로의 사진·로고·하단 설명·CTA 간 위계.
2. 컬렉션 소개에서 왼쪽 제목/정보와 오른쪽 큰 이미지의 비대칭 구도.
3. 컬렉션·상품 사진 사이의 넓은 여백과 절제된 밑줄 링크.
4. 향후 스크롤 연출을 조정할 때 참고할 메뉴 유지·텍스트 등장·이미지 전환의 방향.

## 적용 범위

현재 Figma의 핑크·크림색, 로고, 사진, 텍스트, 메뉴, 섹션 구성은 유지한다.
이 참고 사이트 제공만으로 ROLAROLA의 로고 크기·색상·IA를 변경하거나 GSAP / Lenis를 추가하지 않았다.
새 모션을 구현할 때는 현재 기본 smooth scroll과 구분해 작업 범위를 기록하고, 모바일·키보드·reduced-motion을 함께 검증한다.

참고 화면은 artifacts/eleos-top.png 및 artifacts/eleos-scroll.png에 저장했다. 이는 검토용 스크린샷이며 ROLAROLA 구현 에셋으로 사용하지 않는다.

## 사진 등장 효과 적용

추가 확인한 `initImageReveal`은 덮개를 위로 걷어 사진을 보여준다. 5열 사진의 열별 duration은 0.8초, stagger는 0.06초이며 화면 높이 85%에서 한 번 재생한다.

최종 사용자 요청에 따라 ROLAROLA에서는 세로 띠를 제거하고 왼쪽 아래 모서리에서 오른쪽 위로 펼쳐지는 단일 clip-path 효과로 변경했다. 사진의 위치와 크기를 유지하며 0.8초, cubic-bezier(.76, 0, .24, 1)을 사용한다. 화면 높이 85%에서 한 번 재생하며 con3, con4, con5, con7은 제외한다.
