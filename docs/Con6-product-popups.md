# con6 상품 팝업

- 디자인: Figma `160:1345`, `160:1357`, `160:1369`. 원본 SVG 3개를 로컬 에셋으로 저장했다.
- 참고: https://luminaireauthentik.com/ 의 `.product-button`은 왼쪽 아래 썸네일에서 상품 정보 카드로 펼쳐지며, 1초 cubic-bezier(.33, 1, .68, 1) 전환을 사용한다.
- 각 착장 카드에 호버하거나 상품 썸네일에 키보드 포커스를 주면 해당 팝업이 펼쳐진다. 이탈·포커스 이동·Escape로 닫힌다. 모바일에서는 썸네일을 탭해 열고 바깥을 탭해 닫는다.
- PC 팝업 413×211px, 이미지 95×95px, 정보 시작점 41/33px, 하단 버튼 높이 52px, 모서리 10px. 카드가 좁아지면 같은 비율로 축소한다.
- JetBrains Mono Regular 400을 로컬 폰트로 추가했다.
- 상품명과 가격은 Figma 표기를 그대로 사용했다. popup2의 이미지 색상과 WHITE 표기도 원본을 유지했다.
- 상세 페이지 및 장바구니 연결은 미확정이므로 버튼은 비활성 상태다. 임의 경로나 장바구니 성공 동작을 만들지 않았다.
- reduced-motion 환경에서는 펼침·페이드 전환을 생략한다.
